§ 01

Norte · qué estamos construyendo

FlagMaster es un juego ligero de banderas pensado para jugar en familia. La dirección Atlas editorial apuesta por la estética de libro de exploradores del XIX: papel, sello, brújula, Playfair en cursiva.

La novedad de esta hoja de ruta es transformar el flujo lineal (elegir modo → 10 preguntas → resultado) en un viaje por continentes: empiezas con Europa desbloqueada y vas conquistando el resto del mundo a base de aciertos. Cada continente es un capítulo del atlas.

«Un atlas no se lee de seguido — se viaja. Cada continente es una expedición, cada acierto es un kilómetro recorrido.» Norte editorial

§ 03

Cartografía · modelo de datos

El dataset actual tiene 86 países con bandera, nombre, capital y dificultad. Para activar la mecánica de continentes hay que añadir un campo r (región).

// flagmaster-data.js — modelo extendido
window.FM_COUNTRIES = [
  { f:"🇪🇸", n:"España", c:"Madrid", s:"easy", r:"eu" },
  { f:"🇲🇽", n:"México", c:"Ciudad de México", s:"easy", r:"am" },
  { f:"🇯🇵", n:"Japón", c:"Tokio", s:"easy", r:"as" },
  // … 83 más
];

window.FM_REGIONS = {
  eu: { n:"Europa",    order:1, lock:null },
  am: { n:"Américas",  order:2, lock:{ region:"eu", mastery:0.6 } },
  as: { n:"Asia",      order:3, lock:{ region:"am", mastery:0.6 } },
  af: { n:"África",    order:4, lock:{ region:"as", mastery:0.5 } },
  oc: { n:"Oceanía",   order:5, lock:{ region:"af", mastery:0.5 } },
  is: { n:"Islas",     order:6, lock:{ region:"oc", mastery:0.7 } },
};

Códigos sugeridos: eu Europa · am Américas · as Asia · af África · oc Oceanía · is Islas (challenge final). Si prefieres separar Norte/Sudamérica, divide en na y sa.

§ 04

Mecánica de desbloqueo

Cada continente conserva su estado en localStorage bajo una clave única. Por país guardamos cuántas veces se ha visto y cuántas se ha acertado.

// Persistencia del progreso
const PK = "flagmaster_world_v1";
const world = {
  countries: { "España": { seen:8, hits:7 }, /* … */ },
  regions:   { eu:{ unlocked:true }, am:{ unlocked:true }, as:{ unlocked:false } },
  totalXP:   420,
  stamps:    [ "first-perfect", "europe-cleared" ],
};

// Maestría por región
function regionMastery(regionId){
  const countries = FM_COUNTRIES.filter(c => c.r === regionId);
  const mastered = countries.filter(c => {
    const p = world.countries[c.n];
    return p && p.seen >= 3 && p.hits / p.seen >= 0.66;
  });
  return mastered.length / countries.length;
}

EReglas propuestas

  1. Europa arranca desbloqueada (sin lock).
  2. Cada continente se desbloquea cuando mastery del anterior ≥ umbral (60% para los 3 primeros, 50% para los siguientes, 70% para Islas).
  3. Una bandera está "dominada" tras 3 vistas con ≥ 66% de acierto.
  4. Las partidas tiran preferentemente de la región en curso, pero un 20% del pool viene de regiones ya conquistadas (anti-olvido).
  5. Al desbloquear un continente: animación de sello "EXPEDICIÓN ABIERTA" + sonido + entrada en el diario.

§ 09

Decisiones pendientes

Antes de empezar el Sprint 1 necesitamos cerrar 4 puntos:

  1. Subdivisión de Américas: ¿un solo continente o Norte / Centro+Caribe / Sur?
  2. Orden de desbloqueo: ¿lineal fijo (Europa → Américas → Asia…) o el usuario elige cuál abrir tras el primero?
  3. Umbrales: ¿60% es el filo correcto? Más bajo = más fluido; más alto = más reto.
  4. Reset: ¿permitimos "rehacer" un continente para subir el dominio sin perder progreso?
